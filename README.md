# Statistical Consulting Projects

Three applied statistics projects developed for the *Statistical Consulting* course (B.Sc. in Applied Statistics, Faculdade de Ciências da Universidade de Lisboa, 2025/26).

These were **group projects** carried out by four students (one from Applied Statistics (me) and three from Applied Mathematics). Names are omitted for privacy. The reports are written in Portuguese.

| # | Project | Methods | Software |
|---|---------|---------|----------|
| 1 | [Pharmacy prices across two districts](1-pharmacy-prices/) | Descriptive statistics, Shapiro-Wilk, F test, Student's t-test | SPSS |
| 2 | [Blue carbon and nitrogen storage in salt marshes](2-blue-carbon-salt-marshes/) | Linear regression, ANOVA, Kruskal-Wallis, Tukey and Dunn post hoc tests, correlation | SPSS, R |
| 3 | [Prognostic markers in ICU COVID-19 patients](3-icu-covid19-prognosis/) | Normality tests, Mann-Whitney, Fisher's exact test, relative risk, odds ratios, logistic regression, AIC | R |

## What is and isn't included
Only the final reports/article (PDF) are shared. **Datasets and analysis code are not included**: the data are confidential or belong to third parties.

## Note on AI tools
Generative AI tools were used only for help with LaTeX formatting, as declared in each document.
